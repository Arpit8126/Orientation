1. In a biological neuron analogy, which component of an Artificial Neuron corresponds to the biological synapse?

A) Net input adder

B) Activation threshold

C) Synaptic weight

D) Output axon
Correct Option: C
Explanation: In biological neural networks, synapses modulate the strength of incoming signals. In an artificial neuron, weights scale input values up or down to reflect their relative importance.

2. Which pioneering model introduced the earliest mathematical abstraction of a biological neuron with binary threshold logic?

A) Rosenblatt Perceptron (1958)

B) McCulloch-Pitts Neuron (1943)

C) Widrow-Hoff Adaline (1960)

D) Hopfield Network (1982)
Correct Option: B
Explanation: Warren McCulloch and Walter Pitts formulated the first computational model of a neuron in 1943 using binary threshold operations without learnable weights.

3. What historical event triggered the first major "AI Winter" for artificial neural network research?

A) The inability of Backpropagation to converge on non-convex loss surfaces

B) Minsky and Papert proving single-layer perceptrons cannot solve the XOR problem

C) Rumelhart and Hinton publishing the Generalized Delta Rule

D) The invention of Support Vector Machines displacing multi-layer networks
Correct Option: B
Explanation: In their 1969 book Perceptrons, Marvin Minsky and Seymour Papert mathematically proved that single-layer perceptrons could not separate non-linear functions like XOR, leading to reduced funding and interest.

4. A single artificial neuron has two inputs: x1 = 0.6 and x2 = -0.4, with associated weights w1 = 0.5 and w2 = 0.25, and a bias b = 0.1. What is the net input (z) before applying an activation function?

A) 0.20

B) 0.30

C) 0.40

D) 0.50
Correct Option: B
Explanation: Net input is calculated as: z = (x1 * w1) + (x2 * w2) + b = (0.6 * 0.5) + (-0.4 * 0.25) + 0.1 = 0.30 - 0.10 + 0.10 = 0.30.

5. What is the primary role of the bias term (b) in the mathematical formulation of an artificial neuron?

A) To normalize feature values between 0 and 1

B) To shift the activation curve horizontally away from the origin

C) To eliminate negative inputs before vector multiplication

D) To force the decision boundary to pass through the origin
Correct Option: B
Explanation: The bias acts as a learnable intercept term, allowing the activation function to shift left or right along the axis so the network can activate even when all inputs are zero.

6. Which statement best defines the fundamental concept of "Learning" in machine learning algorithms?

A) Memorizing training samples into a static relational database

B) Manually defining explicit rule-based decision trees for all edge cases

C) Improving task performance over time based on experience or data

D) Compiling human-written source code into low-level machine instructions

Explanation: Machine learning is broadly defined as a program's ability to improve its performance metric (P) on a specific task (T) through historical experience or data (E).

B) Classifying incoming emails as spam or legitimate based on user flags

C) Segmenting e-commerce customers into purchasing groups without predefined labels

D) Forecasting next week's temperature using continuous atmospheric sensor data

9. In a standard Supervised Machine Learning pipeline, why is Feature Scaling performed strictly after the Train-Test Split?

A) To reduce the total training time of computationally heavy models

B) To prevent data leakage of test distribution statistics into training data

C) To ensure target labels remain uncorrupted during vector transformations

D) To automatically eliminate irrelevant or redundant numerical columns
Correct Option: B
Explanation: Computing mean or variance using the entire dataset causes information from the test set to leak into training, yielding overly optimistic evaluation metrics.

10. An artificial neuron receives inputs x1 = 2, x2 = 3, and x3 = -1 with weights w1 = 0.4, w2 = -0.2, and w3 = 0.5. Given a bias b = 0.3, what is the computed net input?

A) 0.0

B) 0.3

C) 0.5

D) -0.1
Correct Option: A
Explanation: Net input is calculated as: z = (2 * 0.4) + (3 * -0.2) + (-1 * 0.5) + 0.3 = 0.8 - 0.6 - 0.5 + 0.3 = 0.0.

11. Which network topology is characterized by directed acyclic graph connections where information moves in strictly one direction without feedback loops?

A) Recurrent Neural Network (RNN)

B) Feedforward Neural Network (FNN)

C) Hopfield Associative Network

D) Boltzmann Machine
Correct Option: B
Explanation: In feedforward architectures, signals travel forward from input through intermediate hidden layers to output nodes without any cyclic connections or recurrent state updates.

12. What distinguishes a Recurrent Neural Network (RNN) from a standard Multi-Layer Perceptron?

A) RNNs only operate on completely unlabeled image data

B) RNNs maintain hidden internal state loops to process sequential dependencies

C) RNNs strictly require non-differentiable step activation functions

D) RNNs do not use weights or bias terms in their computational units
Correct Option: B
Explanation: RNNs incorporate recurrent loops that pass previous hidden-state outputs back into current computations, making them well-suited for temporal and sequential data.

13. What is the mathematical range of the standard Logistic Sigmoid activation function?

A) Range between -1 and 1

B) Range between 0 and 1

C) Range between 0 and positive infinity

D) Range between negative infinity and positive infinity
Correct Option: B
Explanation: The Sigmoid function maps real-valued numbers into the open interval (0, 1), making it useful for representing probabilities in binary classification.

14. What primary limitation of the Sigmoid activation function led to the widespread adoption of ReLU in deep hidden layers?

A) Sigmoid functions cannot compute outputs for positive inputs

B) Sigmoid creates extreme exploding gradients in shallow networks

C) Sigmoid gradients saturate near 0 for high or low inputs, causing vanishing gradients

D) Sigmoid output is unbounded on positive values, destabilizing training
Correct Option: C
Explanation: When inputs become very large positive or negative values, the derivative of the Sigmoid function approaches zero, halting weight updates during backpropagation in deep networks.

15. How does the Hyperbolic Tangent (Tanh) activation function differ from the standard Sigmoid function?

A) Tanh is zero-centered with an output range from -1 to 1

B) Tanh is strictly non-differentiable across its entire mathematical domain

C) Tanh outputs values strictly bounded between 0 and positive infinity

D) Tanh completely eliminates the vanishing gradient problem across deep networks
Correct Option: A
Explanation: Tanh produces outputs in the range (-1, 1) and is zero-centered, which generally prevents systematic directional bias during gradient descent weight updates.

16. An artificial neuron computes net input z = -1.85. If this neuron uses the standard Rectified Linear Unit (ReLU) activation function, what is the final output?

A) -1.85

B) -1.00

C) 0.00

D) 1.85
Correct Option: C
Explanation: The ReLU activation function is defined as f(z) = max(0, z). For any input less than or equal to 0, the output is clamped to 0.

17. What problem can occur in deep networks when using standard ReLU if a neuron's weights are updated such that its net input is always negative?

A) Exploding Weight Drift

B) Saturated Unit Oscillation

C) Dying ReLU Phenomenon

D) Gradient Inversion Bias
Correct Option: C
Explanation: If a ReLU neuron consistently receives negative net input, its output and derivative remain permanently zero, causing gradient updates to freeze permanently.

18. How does the Leaky ReLU activation function address the limitation of the standard ReLU function?

A) It caps positive values at 1.0 to prevent gradient explosions

B) It assigns a small, non-zero constant slope to negative inputs

C) It transforms negative values using a periodic trigonometric cosine function

D) It normalizes negative outputs so they sum to 1.0 across the layer
Correct Option: B
Explanation: Leaky ReLU introduces a small positive slope (e.g., 0.01) for negative inputs, ensuring a non-zero derivative that keeps weights updating.

19. Which activation function is most appropriate for the output layer of a mutually exclusive multi-class classification neural network?

A) Binary Step Function

B) Hyperbolic Tangent (Tanh)

C) Softmax Function

D) Standard ReLU
Correct Option: C
Explanation: The Softmax function converts an unnormalized vector of real numbers into a normalized probability distribution where all values lie between 0 and 1 and sum to 1.

20. What is the fundamental purpose of including non-linear activation functions in deep neural networks?

A) To reduce memory footprint during forward propagation passes

B) To enable the network to learn and approximate complex non-linear decision boundaries

C) To guarantee that all network weights converge to exact zero values

D) To convert real continuous inputs into discrete categorical integer codes
Correct Option: B
Explanation: Without non-linear activation functions, stacking multiple dense layers collapses mathematically into a single linear transformation, preventing the model from learning non-linear relationships.

21. A neuron uses an identity (linear) activation function f(z) = z. It receives inputs x1 = 4, x2 = 1 with weights w1 = 0.5, w2 = -2, and a bias b = 1. What is the neuron's final activated output?

A) 0

B) 1

C) 2

D) 3
Correct Option: B
Explanation: Net input is computed as: z = (4 * 0.5) + (1 * -2) + 1 = 2 - 2 + 1 = 1. Applying the linear identity function f(1) = 1 yields 1.

22. In the supervised machine learning pipeline, what is the primary role of Cross-Validation?

A) To generate synthetic training samples for underrepresented target classes

B) To reliably estimate generalizability and prevent overfitting on a single split

C) To reduce the dimensionality of multi-collinear numerical input spaces

D) To automate the selection of optimal loss functions during backpropagation
Correct Option: B
Explanation: Cross-validation (such as k-fold) evaluates model stability and performance across multiple distinct subsets of data, providing a more robust estimate of how the model generalizes.

24. What critical advancement did the Adaline (Adaptive Linear Neuron) introduce to neural network history?

A) Multi-head self-attention mechanisms for natural language processing

B) Using the continuous Delta Rule (LMS) to update weights before thresholding

C) Convolutional kernels for spatial translation invariance in vision

D) Gated recurrent memory cells to retain long-range temporal contexts
Correct Option: B
Explanation: Developed by Bernard Widrow and Ted Hoff, Adaline introduced the Least Mean Squares (LMS) / Delta Rule, updating weights using continuous linear errors rather than discrete step outputs.

25. Which element of an Artificial Neuron combines incoming feature signals with their corresponding connection strengths into a scalar value?

A) Squashing function

B) Summation function

C) Error regularizer

D) Threshold comparator
Correct Option: B
Explanation: The summation function (adder) calculates the dot product of input vectors and weight vectors, then adds the bias to produce the scalar net input.

26. In Semi-Supervised Learning, how does the model typically utilize available data?

Explanation: Semi-supervised learning addresses scarce annotation scenarios by using abundant unlabeled data to learn structure alongside a small labeled set for supervision.

29. What occurs when a supervised model overfits the training data during pipeline evaluation?

A) High training error paired with high validation error

B) Low training error paired with significantly higher validation error

30. Which mathematical operation represents the net input calculation for a neuron with n inputs, weights, and a bias?

A) Multiply all inputs together and divide by the bias

B) Compute the sum of all weight-input products and add the bias

C) Take the maximum value among all weighted inputs and subtract the bias

D) Apply a step threshold directly to raw inputs and average the results
Correct Option: B
Explanation: The net input (z) is the linear combination of inputs and their respective weights plus the bias term: z = (w1x1 + w2x2 + ... + wn*xn) + b.
